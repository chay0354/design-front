# PETITE DREAMS — בדיקת כיסוי של מסמך התוספות

כל שורה במסמך הדרישות, ומה נבנה עבורה.
✅ בוצע · 🟡 בוצע חלקית או עם הסתייגות · ⏳ לא בוצע (מסומן במסמך כ"אחרי ההשקה" או תלוי בגורם חיצוני)

בדיקות: 23 בדיקות יחידה בבקאנד (`npm test`) ו-11 בדיקות דפדפן מול API מדומה (`npm run test:e2e:mocked`).
מה **לא** נבדק: ריצה מול Supabase אמיתי, סליקה אמיתית ומיילים אמיתיים.
